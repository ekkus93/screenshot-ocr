# Security policy

Please report suspected screenshot leakage, OCR-text leakage, arbitrary command execution, path traversal, symlink races, unsafe temporary-file handling, clipboard corruption, or capability expansion privately to the repository owner before public disclosure.

Include the affected commit, operating system/session, minimal reproduction steps using synthetic data, and whether any real secret may have been exposed. Do not attach private screenshots, real credentials, or raw OCR output to public issues.

The application is pre-release. Security reports for supported versions receive priority over feature work.
